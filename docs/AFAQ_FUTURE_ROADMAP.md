# AFAQ future roadmap — planning only after Phase 5

Not implemented or represented as working Phase 5 capabilities:

- An original, distinctive interactive educational mascot with Arabic educational identity. It must be separate from and must not replace the official AFAQ logo. Existing learning companion remains unchanged; no new mascot artwork was created.
- Automatic Arabic speaking feedback: needs validated Arabic speech evidence, consent/privacy design and human evaluation. No pronunciation scoring or external speech API in Phase 5.
- Teacher-reviewed photographed handwriting assignments: camera/file consent, safe retention, real teacher rubric and review workflow before any result is claimed.
- AI educational assistant: curriculum-constrained and evaluated before exposing it to children; infrastructure/provider decisions require separate approval.
- Parent-teacher communication and live tutoring with an interactive whiteboard: identity, authorization, moderation and service design are future work. Existing local board is preserved.
- Secure student accounts and subscriptions: actual authentication/authorization and explicit infrastructure approval. A local teacher switch is not protection.
- Integrated personalized remediation and progress evidence: extend existing adaptive targeting and evidence separation; do not replace or reset existing records. Validate dictation, oral reading, listening and comprehension coverage before expanding claims.

Phase 5 reports explicitly mark missing/insufficient evidence as لم يُقيّم. A report category does not establish that an automatic assessment exists.
