# المرحلة الأولى — بنية مسار تعلم العربية العام

التاريخ: 2026-11-13 بتوقيت الرياض. نُفذت ترقية تدريجية داخل المشروع القائم دون إعادة بنائه أو تغيير بنوك المحتوى. نجحت مجموعات الاختبار السابقة الإحدى عشرة والمجموعتان الجديدتان: **13/13**، وتطابقت النسخة النهائية مع بصمات النسخة المختبرة.

## البنية

`arabic-learning-path.js` طبقة وصف وربط وعرض نقية، لا تخزن تقدمًا ولا تنشئ محرك تكيف ثانٍ. تستدعي قواعد ومحرك المشروع الحاليين. العلاقات قابلة لإعادة الاستخدام عبر المناهج:

`مجال تعلم → مهارة → عالم → مستوى → درس → نشاط`

- خمسة مجالات لغوية: القراءة والكتابة والاستماع والتحدث والفهم والتحليل؛ ومجال دعم إضافي للاستعداد المعرفي. الألعاب نوع نشاط مرتبط بمهارة، وليست كفاية لغوية مستقلة.
- سبعة عوالم قابلة للتهيئة عبر `defaultConfig` و`createCatalog(rules, options)`. العضوية التعليمية والمتطلبات ليست سلسلة عالمية مفروضة على كل منهج.
- عُرّف 193 مرجع نشاط مطابق لمعرفات الأنشطة الموجودة؛ ليست أنشطة أو أسئلة جديدة. توجد 196 مستويات ودروس وصفية: مرجع لكل نشاط حالي، وثلاثة دروس مخططة بلا محتوى مختلق.
- 181 مرجعًا لمحتوى منفذ، و12 مرجعًا غير متاح لمهام الصوت وقراءة الكلمات غير المنفذة في الوحدة الثانية. عوالم الجمل والتواصل والطلاقة والتطبيق المتقدم مخططة؛ لا تُمنح لها نتائج أو إتقان.
- معرفات ثابتة وإصدار 1 وأنواع وعناوين وحالات ومتطلبات وروابط بين المستويات والدروس والأنشطة. النشاط يحتفظ بـ`sourceActivityId` الأصلي، فلا تُعاد تسمية معرفات سجلات التعلم.

المستوى الحالي يمثل درسًا قصيرًا واحدًا مشتقًا من نشاط موجود. تبقى مراحل الاكتشاف والتدريب الموجه والمستقل والمراجعة والتقييم داخل منفذ النشاط الحالي. توسيع التجميع إلى دروس مركبة ومجموعات أنشطة داخل مستوى يحتاج تصميم واستيراد المرحلة التالية واختباراته؛ لا تدعي هذه المرحلة بناء جميع دروس العربية.

## ما يعمل الآن

- `journey-rules.js`: تحقق من المعرفات والمتطلبات المفقودة والدورات، و`createRules` لبناء رسم موجه قابل للتفرع والاعتماد بين المهارات. ترتيب التوصية لا يضيف قفلًا اعتباطيًا.
- `adaptive-learning.js`: تظل أولوية الواجب، وعلاج التعثر، والمراجعة المتباعدة، وأدلة الانتقال، وتجاوزات المعلم في المحرك نفسه. أضيف `recommendLesson` لإرجاع الدرس والمستوى والعالم، و`legacyView` لإسقاط أدلة التقييم القديم دون ترحيلها. يُرفض الرسم الدائري، وتُستبعد الدروس المخططة وغير المتاحة.
- أصبح تمرير محرك الأدلة صريحًا في القواعد عند الحاجة؛ يعمل التحقق من سجلات الإصدار الثاني داخل Chrome وخارجه دون الاعتماد على وجود متغير متصفح عالمي أو اعتبار نتائج غير موثقة دليلًا.
- صفحة الطالب تعرض العالم الحالي والدرس الموصى به والتقدم، وزر «تابع رحلتك» أساسي. يفتح «اكتشف مسارك» خريطة عربية فعلية للعوالم والمستويات المتاحة والمنجزة والمقفلة والمخططة. يستطيع الطالب فتح مستوى متاح والعودة إلى المسار؛ لا يختار وحدات المنهج في الرحلة الافتراضية.
- التقدم يعتمد على أدلة تعلم كافية، ولا يساوي عدد الإجابات أو السرعة. تجاوز المعلم وحده لا يزيده، والقفل أو عدم الإتاحة لا يمحو الدليل السابق. تظهر المراجعة المتباعدة المثبتة منفصلة عن مجرد الجاهزية للانتقال؛ المطابقة المرئية لا تثبت النطق أو الخط.
- عند انتهاء المحتوى المتاح لا يعاد الطالب إلى عالم التهيئة، ولا يرسل إلى عالم مخطط. تبقى نهاية المسار موجهة إلى المعلم بدل حلقة تكرار.
- ترتبط إتاحة المسار بقيود المعلم وتوافر المفردات والأسئلة. لا يفتح مسار الطالب بنكًا إضافيًا لتجاوز قيود المعلم، ولا تُقترح لعبة كلمات بلا مفردات مدروسة كافية.
- أصلح اختبار السجل القديم خطأ بدء الصفحة قبل تحميل البنك: الانتظار يعطل زر البدء، ثم يعاد عرض المسار عند حدث جاهزية المنهج. أخطاء التحميل لها حالة واضحة دون تغيير السجل.
- الواجهة RTL ومتجاوبة؛ Tajawal لعناصر الواجهة وNoto Naskh Arabic للنص التعليمي. بقي الاسم الحالي للمشروع ومساره وهوية التطبيق.

## ربط المنهج وإعادة الاستخدام

سجل الربط يحدد المنهج والصف والوحدة ودرس المنهج والمهارة والمستوى والدرس والنشاط. يمكن إسناد النشاط نفسه إلى منهج آخر بإضافة `additionalMappings` دون تكرار النشاط أو التقدم. اختُبر منهجان يشيران إلى المرجع نفسه، وكذلك رسم متفرع بمتطلبات بين مهارات مختلفة.

يربط المحول الافتراضي محتوى «لغتي» المنفذ في الوحدتين الأولى والثانية والتهيئة، ويبقي ترتيب م، ب، ل، د، ن، ر ثم ص، ف، س، ق، ت، ح وقيود الحروف والمفردات التراكمية. بقي `data/curriculum.json` بكل وحداته الثماني كما هو، وكذلك التنقل الأصلي؛ لا يعني الربط الحالي تنفيذ الوحدات الثالثة إلى الثامنة داخل المسار الجديد. توسيع تغطيتها يحتاج محتوى معتمدًا، لا نسخًا شكلية لملء العوالم.

أعيد استخدام بنوك الأسئلة، والأنشطة الإضافية التكيفية، ومستويات التهيئة الـ46، وألعاب الكلمات، والسبورة، والتقييمات، والصوت وإعداداته، والملفات المحلية ولوحة المعلم وواجباتها. لم يُضف نطق تعليمي آلي أو خادم أو نظام حسابات أو رسوم متحركة أو حماية هوية وهمية.

## توافق البيانات والحماية

لا يوجد مخزن تقدم جديد أو تغيير صيغة أو ترحيل تلقائي. التحليل وبيانات الخريطة مشتقة أثناء العرض. بقيت معرفات الأنشطة القديمة ومفتاح الرحلة وحقوله غير المعروفة وسجلات المحاولات والواجبات كما هي. تُقرأ أدلة الوحدة الأولى المؤكدة للملف المحلي الافتراضي دون إنشاء محاولات مكررة؛ لا تتحول الدرجة القديمة أو العمل غير الموثق إلى إتقان مفترض.

اختُبرت قراءة تقييم تاريخي مؤكد وعرض إنجازه دون إضافة أي تشغيل للرحلة، وبقاء بايتات تخزين الوحدتين والسجل القديم، وإعدادات الصوت، وحفظ الواجب، ورفض استبدال بيانات تالفة والتراجع عند فشل الحفظ. تستخدم الاختبارات ملفات Chrome منفصلة وطلابًا تجريبيين؛ لم يُفتح ملف متصفح الطالب الشخصي.

النسخ المرجعية محفوظة في `.access-staging/universal-phase1-1794519341516/`؛ ومرجع `app.js` مطابق لبصمة النسخة المختبرة قبل المرحلة. النسخة الخارجية السابقة والنسخ الاحتياطية القديمة لم تعدل. ثبتت مطابقة 7 ملفات مرجعية محمية و27 ملفات بيانات مع بصماتها المرجعية. تفاصيل الحفظ في [سجل الحماية](UNIVERSAL_PATH_PHASE1_PRESERVATION.json).

لم تنفذ أوامر reset أو clean أو checkout أو commit أو push أو نشر. بقيت تعديلات العمل السابقة محفوظة، ولم يُطلب أن تكون شجرة Git نظيفة.

## الحدود والمراجعة البشرية

- العوالم اللاحقة وصفية مخططة؛ لا يوجد محتوى جمل أو طلاقة أو تطبيق متقدم جديد معتمد. لا يتوافر بنك مستقل كامل لصوت/قراءة كلمات الوحدة الثانية.
- التهيئة والإعدادات قابلة للامتداد عبر واجهة JavaScript وبياناتها؛ لا توجد واجهة استيراد ملفات أو محرر مناهج رسومي أو اختيار عدة مناهج محفوظ لكل طالب في هذه المرحلة.
- التشخيص الحالي قصير لكل مهارة عبر المحرك السابق، وليس اختبار تحديد مستوى لغوي شاملًا. إبقاء التسلسل السعودي لا يمنع رسومًا متفرعة عند إضافة محول منهج آخر.
- المتصفح الآلي لا يعتمد النطق أو التشكيل دلاليًا أو جودة الكتابة وملاءمة الجلسة للأطفال. تلزم مراجعة معلم عربي، والاستماع للتسجيلات وفحص الخط على أجهزة حقيقية وتجربة مبتدئين.
- وضع المعلم والرمز المحلي تنظيم على الجهاز، لا حساب آمن أو تفويض خادم. لم تُبنَ مصادقة أو خدمة مزامنة. تبقى حدود التخزين المحلي والسجلات القديمة المشتركة الموضحة سابقًا.

## خطة المرحلة الثانية المقترحة

1. اعتماد خريطة المهارات والمتطلبات تربويًا، وتحديد أدلة مستقلة لكل من القراءة والاستماع والتحدث والكتابة والفهم؛ مراجعة المحتوى المخطط قبل إتاحته.
2. إضافة استيراد مناهج بإصدار ومخطط تحقق ومعاينة أخطاء المتطلبات والربط، ثم محرر معلم وتجميع دروس مركبة واختيار منهج للملف المحلي؛ تبقى معرفات الأنشطة مشتركة.
3. بناء تحديد مستوى شامل ومسارات متفرعة من أدلة حقيقية، مع إبقاء الواجب والتجاوز والمراجعة في المحرك الحالي، واختبارات توافق للملفات القديمة.
4. تنفيذ محتوى الجمل والتواصل والطلاقة تدريجيًا بعد مراجعة بشرية، ثم تحسين تقارير المعلم وولي الأمر. يمكن للمرافق والمكافآت الاستفادة من واجهات التوصية والعرض دون أن تصبح دليل إتقان.
5. تصميم الحسابات والتفويض والتخزين الخادمي الآمن والمزامنة كمرحلة مستقلة مصرح بها، مع نسخ وترحيل قابل للتراجع؛ لا رفع لبيانات محلية ضمن هذه المرحلة.
